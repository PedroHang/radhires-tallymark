Check an extraction for anything left on the drawing

Tallymark reads your drawing on its own, greys out every requirement that a Bill of Characteristics row already covers, and lights up only what no row covers. Run it after the BoC is built and before you inspect, so one missing row doesn't get your First Article report rejected.

  • You loadthe drawing (PDF or TIFF) and the BoC built from it (CSV or Excel).
  • You geta short list of flags on the drawing: U a requirement with no row, P a "4X" style callout whose row counts fewer places.
  • You decideconfirm, exclude or dismiss each flag, then export the exceptions as a CSV.

    The drawing

    The engineering drawing of the part, every sheet. It is the file the inspector measures against, at the same revision the BoC was built from.

    Formats
    PDF (vector or scanned) or TIFF
    Limits
    Up to 50 MB and 20 sheets
    The Bill of Characteristics

    The list your extraction tool built from the drawing: one row per requirement, the same list that becomes AS9102 Form 3. Tallymark checks it against the drawing.

    Formats
    CSV or Excel (.xlsx, .xlsm), including an AS9102 Form 3 sheet
    Needs
    char_no, sheet (or a "Sheet 2, zone B3" location), requirement
    Helps
    places and the location box bbox_x, bbox_y, bbox_w, bbox_h
    Reason
    Export exceptions
    Format: CSV
    Settings
    Display
    Interface sizeScales text and controls. Ctrl+Alt+= / Ctrl+Alt+- also work.
    Exclusions

    Rules differ by customer. Exclusions only hide regions, they never delete BoC rows.

    Model check

    Only ambiguous leftovers (a bare number with no tolerance or frame) are shown to the model, as a crop. Rules decide every other flag.

    Works with an Anthropic, OpenAI or Google Gemini key: paste any of them and the provider is picked from the key. Keys stay in the local server's memory and are never written to run files. Claude Pro/Max subscription tokens (sk-ant-oat...) are meant for Claude Code; the API may reject them here, so a Console API key is the reliable option.
